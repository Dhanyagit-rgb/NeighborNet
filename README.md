# NeighborNet 🛡️
> Hyper-Local Community Emergency Alert & Care System

## 1. Problem
Standard emergency services and traditional panic apps focus strictly on life-threatening medical or police events. They ignore daily non-ambulance emergencies—such as mobility assistance, urgent medication pickup, or minor falls experienced by seniors living alone.

## 2. Solution
NeighborNet is a 1-tap alert platform that broadcasts non-ambulance emergency alerts simultaneously to personal trusted contacts and vetted nearby volunteers within walking distance.

## 3. Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (Mobile-responsive)
- **Deployment:** GitHub Pages
